 🌦️ Weather API Client (Python)

A simple Python-based project that fetches real-time weather data using the Open-Meteo API.

This project was built to understand the fundamentals of backend development using Python, including API integration, JSON handling, and error management.

---

## 🚀 Features

- 📡 Fetch real-time weather data using Open-Meteo API
- 🌡️ Displays temperature
- 💧 Displays humidity
- 🌬️ Displays wind speed
- ⚠️ Basic error handling using try/except
- 🪵 Logging for request tracking
- 📁 Stores weather data in local files (JSON/text)
